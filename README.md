## 🔹 If Statement

The `if` statement is used to execute a block of code when a specified condition is true.

```cpp
if (condition) {
    // code to execute
}
```

## 🔹 If-Else Statement

The `if-else` statement allows a program to choose between two possible outcomes.

```cpp
if (condition) {
    // code if condition is true
}
else {
    // code if condition is false
}
```

## 🔹 If-Else-If Statement

The `if-else-if` structure is used when a program needs to evaluate multiple conditions.

```cpp
if (condition1) {
    // first condition
}
else if (condition2) {
    // second condition
}
else {
    // if none of the conditions are true
}
```

## 🔹 Switch Statement

The `switch` statement is useful when a program needs to select one option from multiple fixed choices.

```cpp
switch (choice) {
    case 1:
        // option 1
        break;

    case 2:
        // option 2
        break;

    default:
        // invalid option
}
```
